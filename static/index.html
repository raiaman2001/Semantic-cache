Drop-In Base URL

Zero Codebase Architecture Changes

Point any OpenAI SDK, LangChain, or custom client's base_url to this proxy address. All requests hit L1/L2 cache before falling back to your LLM.

http://localhost:8000/v1

Client SDK Snippets

python 
from openai import OpenAI

# 1. Point client to your Semantic Cache Proxy
client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed"  # Or your X-API-Key if security enabled
)

# 2. Call chat completions normally
response = client.chat.completions.create(
    model="gpt-4o",  # Or your model name
    messages=[
        {"role": "user", "content": "How do I reset my password?"}
    ]
)

# 3. Print answer (Hits L1/L2 in <15ms on repeated/similar queries!)
print(response.choices[0].message.content)
python 
from langchain_openai import ChatOpenAI

# Drop-in LLM wrapper pointing to Semantic Cache
llm = ChatOpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed",
    model="gpt-4o"
)

# Automatically cached across all LangChain chains & agents
response = llm.invoke("What is Retrieval-Augmented Generation?")
print(response.content)
javascript 
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:8000/v1",
  apiKey: "not-needed",
});

const completion = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "How to install Python on Windows?" }],
});

console.log(completion.choices[0].message.content);
